# דיווח שעות (Reporting-hours)

אפליקציית אנדרואיד לדיווח עצמי של מרצים על שעות עבודה לפי מקום עבודה:
שעות אקדמיות, הפסקות, שכר, נסיעות וסיכומים חודשיים.

החזון המלא ותוכנית העבודה: [WISHLIST.md](./WISHLIST.md).

## סטאק

- **React Native + Expo (SDK 57)** ב־TypeScript — קוד אחד שרץ גם כ**אתר** (react-native-web)
  וגם כ**אפליקציית אנדרואיד**.
- **expo-router** לניווט מבוסס־קבצים (תיקיית `app/`).
- כיווניות **RTL** נכפית דרך [lib/rtl.ts](./lib/rtl.ts) ובתבנית ה־HTML [app/+html.tsx](./app/+html.tsx).
- אחסון מקומי בלבד בשלב זה (ללא שרת) דרך `@react-native-async-storage/async-storage`,
  שממופה ל־`localStorage` ב־web. עטיפת JSON: [lib/storage.ts](./lib/storage.ts).

## אתר (web)

- בנייה מקומית: `npm run build:web` → פלט סטטי בתיקיית `dist/`.
- פריסה: workflow ב־[.github/workflows/deploy-web.yml](./.github/workflows/deploy-web.yml)
  בונה ופורס ל־**GitHub Pages** בכל push ל־`main`.
- כתובת: `https://yanivmalka.github.io/Reporting-hours/`
  (דורש הפעלה חד־פעמית: Settings → Pages → Source = "GitHub Actions").
- ה־`baseUrl` מוגדר ל־`/Reporting-hours` ב־`app.json` בשל נתיב ה־project-site של Pages;
  יש לשנותו אם עוברים לדומיין ייעודי.

## APK (אנדרואיד)

- **בנייה אוטומטית:** [.github/workflows/build-apk.yml](./.github/workflows/build-apk.yml) רץ בכל push ל־`main`
  (או ידנית מ־Actions): `expo prebuild` → `gradlew assembleRelease` → פרסום **GitHub Release**
  בשם `v0.1.<מספר בנייה>` עם קובץ ה־APK.
- **הורדה:** `https://github.com/yanivmalka/Reporting-hours/releases/latest`
- **עדכון מתוך האפליקציה:** [lib/update.ts](./lib/update.ts) בודק בפתיחה את ה־Release האחרון ומשווה
  למספר הבנייה המותקן (`extra.buildNumber`, מוזרק ב־[app.config.js](./app.config.js)). אם יש חדשה —
  חלון "עדכון זמין": ה־APK יורד בתוך האפליקציה עם פס התקדמות (expo-file-system), ואז נפתח מתקין החבילות
  של אנדרואיד (expo-intent-launcher, הרשאת REQUEST_INSTALL_PACKAGES). בתפריט הצד: הגרסה המותקנת וכפתור "בדיקת עדכונים".
- **חתימה:** עדכון מותקן רק אם נחתם באותו מפתח. אם הוגדרו הסודות `ANDROID_KEYSTORE_BASE64`,
  `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` — נחתם בהם; אחרת במפתח ה־debug הקבוע של תבנית Expo
  (יציב, אך ציבורי). מעבר בין המפתחות מחייב הסרה והתקנה מחדש פעם אחת.
- בהתקנה הראשונה יש לאשר "התקנה ממקורות לא ידועים" לדפדפן.

## לוח בקרה (דשבורד)

`app/dashboard.tsx` + חישובים טהורים ב־[lib/dashboard.ts](./lib/dashboard.ts) ורכיבי גרפים ב־`components/Charts.tsx` (Views בלבד, ללא ספרייה):
- **תקופת שכר לכל מקום עבודה** לפי יום התשלום (מיום התשלום ועד יום לפני הבא) — נוכחית / קודמת.
- אריחי מדד: סכום עד כה, שעות אקדמיות ורגילות, ימי עבודה, נסיעות, דקות מצטברות, ממוצע ליום.
- תשלומים קרובים (סכום צפוי, ימים לתשלום, התקדמות התקופה) · מגמה חודשית (שכר / שעות / נסיעות)
  · פילוח לפי מקום עבודה · שבוע עבודה טיפוסי · עיגול שעות (דקות עודפות שהועברו למונה / נכללו).
- במסך הבית: כרטיס "החודש עד כה" שמוביל ללוח הבקרה.

## קורסים קבועים

[lib/courses.ts](./lib/courses.ts) — קורס מחזורי למקום עבודה: יום בשבוע, שעות קבועות, הפסקה ותקופה
(חודש אחד / 3 חודשים / סמסטר א׳–ב׳–קיץ, או תאריכים חופשיים). ניהול מתוך מסך עריכת מקום העבודה
(`app/course-form.tsx`). בדיווח — "מהמערכת השבועית": בחירת קורס ממלאת שעות, הפסקה ונושא.
ברשימת מקומות העבודה — שעות החודש מול המתוכנן בקורסים (או מול ממוצע החודשים הקודמים).

## דוחות שכר

[lib/payroll.ts](./lib/payroll.ts) — דוח שעות חודשי לכל מקום עבודה, לפי "החודש" שלו (מיום התשלום ועד הבא):
פירוט שעות לכל קורס (מפגש־מפגש), סה״כ שעות וסה״כ נסיעות. במקום העבודה מגדירים מייל לשכר וכתובות להעתק.
- `app/payroll.tsx` — ממתינים לשליחה (חודש שנסגר, יש דיווחים, לא סומן כנשלח) · החודש הנוכחי בהכנה · נשלחו.
- `app/payroll-report.tsx` — תצוגת הדוח, **יצירת מייל לשליחה** (mailto: לתוכנת המייל של המכשיר, עם נמען, העתק,
  נושא וגוף), שיתוף/העתקה, וסימון כנשלח.
- תזכורת (`components/PayrollReminder.tsx`) במסך הבית ובלוח הבקרה כשיש דוחות ממתינים.

## היסטוריית תנאים, מס ותשלומים

- **היסטוריית תנאים** (`Workplace.termsHistory`, `workplaceAt`): שינוי תעריף / סוג תשלום / נסיעות / מס חל
  מתאריך שבוחרים; דיווחים קודמים מחושבים לפי התנאים שחלו בתאריך שלהם.
- **אחוז מס**, **מספר עובד**, **תיאום מס** לכל שנה לועזית (`app/tax.tsx`).
- **פרטים אישיים** (`app/profile.tsx`) — חתימת מיילי השכר.
- **דוח שכר**: תעריף, שכר וסכום לתשלום (באפליקציה); במייל — טבלת מפגשים בלי הפסקות ובלי תעריף, עם סכום לתשלום.
  ביטול דוח שנשלח מחייב סיבה; דיווחים בחודש שהדוח שלו נשלח נעולים לעריכה.
- **מעקב תשלומים** (`app/payments.tsx`): תאריך וסכום שהתקבל (מוצע נטו לפי אחוז המס), תזכורת לתשלום באיחור.
- תזכורות במסך הבית: דוחות ממתינים, תשלומים באיחור, תיאום מס חסר.

## נתוני הדגמה וניהול נתונים

- בהפעלה הראשונה (אין מקומות עבודה ודיווחים) נטענים אוטומטית נתוני הדגמה — [lib/demo.ts](./lib/demo.ts):
  4 חודשים, 8 סמינרים, 1–3 סמינרים ביום (א׳–ה׳), 5–9 שעות אקדמיות ביום, "תולדות האדריכלות" שנה א׳
  וסדנאות מטבחים / חדרי רחצה / פרויקט גמר (וילה ומבנה ציבור), עם דקות עודפות במונה ושעות שנפדו.
- מסך **ניהול נתונים** (`app/data.tsx`): טעינה מחדש של ההדגמה · איפוס נתוני הדגמה (מקומות עבודה, העדפות
  ודיווחים אמיתיים נשמרים) · איפוס כל המידע.
- לכל דיווח שדה רשות "נושא / הערה".
